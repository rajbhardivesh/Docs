RF Hunter Hardware & Architecture

RF Hunter is designed around an optimized hardware architecture that maximizes the capabilities of the ESP8266 microcontroller while providing discrete, dedicated subsystems for RF, infrared, display, and input controls.

Technical Specifications​

Flash Memory4 Megabytes (32 Megabits) SPI FlashConfigured under 4M2M (1 MB Sketch / 2 MB LittleFS)
SRAM80 KB User RAM + 32 KB IRAMHigh-performance execution buffer
Display1.3-inch SH1106 Monochrome OLED128x64 resolution, high contrast, I2C bus interface
RF RadioNordic Semiconductor nRF24L01+2.4 GHz transceiver with LNA amplifier, SMA antenna port
Infrared TX940 nm High-Output IR LEDTransistor-driven @ GPIO 15 for extended range

Control Interface6-Tactile Button KeypadPrecision analog voltage divider ladder on single ADC pin (A0)
Power ManagementUSB Type-C 5V InputOnboard 3.3V low-dropout (LDO) linear regulator

Memory Partition Scheme (4M2M)​

RF Hunter firmware is built specifically for the 4M2M (4 MB Flash with 2 MB LittleFS) partition architecture:

+-----------------------------------------------------------------------+
| 0x000000                      4 MB FLASH (32 Mb)                      |
+-----------------------------------+-----------------------------------+
|     Sketch / Firmware Binary      |      LittleFS File System         |
|         (IROM0 Segment)           |        (Persistent Storage)       |
|            Max: ~1.0 MB           |               2.0 MB              |
|        [Embedded IR Database]     |   [Captured Passwords / Custom IR]|
+-----------------------------------+-----------------------------------+

Segment Allocations​

  • Sketch / Firmware Segment (1,044,464 bytes max):
    • Houses the core firmware binary, Wi-Fi Deauther engine, WiPhi captive portal, Nordic RF Jammer routines, display drivers, and the compressed Embedded IR Database (193 remotes, 4,966 buttons).
  • LittleFS Persistent Segment (2,097,152 bytes):
    • Stores newly learned Infrared remotes (/infrared/*.ir), WiPhi attack dumps (/WifiPhish/), and user configuration files.
    • Can be inspected, downloaded, and edited in real time via the onboard Storage Web Portal.
  • EEPROM Emulation Segment (4,096 bytes):
    • Stores WiPhi offline captured credentials, button calibration thresholds, and system boot counters safely across power cycles.
