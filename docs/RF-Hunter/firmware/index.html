Firmware Flashing & Setup

RF Hunter can be updated or restored using the official browser-based web flasher (no software installation required) or compiled manually from source code using Arduino IDE or Arduino CLI.

Method 1: Web Flasher (Recommended)​

The fastest and most reliable way to update or restore RF Hunter is via the RDH Robotics Official Web Flasher.

  • URL: flasher.rdhrobotics.in
  • Requirements: Google Chrome, Microsoft Edge, Brave, or any browser supporting the Web Serial API.

⚡ Open RDH Web Flasher

Step-by-Step Flashing Procedure​

  1. Connect RF Hunter to your computer using a high-quality USB Type-C data cable.
  2. Open flasher.rdhrobotics.in in your Chromium browser.
  3. Click the Connect button.
  4. A browser permission pop-up will display detected serial devices. Select your device port (e.g., USB-SERIAL CH340 or Silicon Labs CP210x) and click Connect.
  5. Select RF Hunter Official Firmware from the firmware dropdown.
  6. Click Install / Flash.
  7. The web flasher will automatically:
    • Erase flash sectors
    • Flash the partition table
    • Program the firmware binary
    • Flash the default LittleFS filesystem
  8. Once completed, RF Hunter will automatically reboot with the fresh firmware ready to use.

Method 2: Arduino IDE 2.x Manual Build​

If you want to customize features, modify code, or compile your own firmware build:

1. Install Arduino IDE & Drivers​

  • Download and install Arduino IDE 2.x.
  • Install the USB UART driver for your RF Hunter board (usually CH340 or CP2102).

2. Configure Board Manager URL​

  1. In Arduino IDE, go to File > Preferences.
  2. In the Additional boards manager URLs field, add: 
    https://darthcloud.github.io/esp8266-deauther/package_esp8266_deauther_index.json,http://arduino.esp8266.com/stable/package_esp8266_com_index.json
  3. Click OK.
  4. Go to Tools > Board > Boards Manager..., search for deauther or esp8266, and install the board package.

3. Install Required Libraries​

Open Tools > Manage Libraries... and install:

  • RF24 (by TMRh20)
  • IRremoteESP8266 (by crankyoldgit)
  • Adafruit GFX Library
  • Adafruit SH110X

(Bundled libraries like ArduinoJson 5.13.5 and display drivers are already integrated in /src/).

4. Board & Partition Settings​

Under the Tools menu, select the following exact parameters:

OptionSetting
BoardESP8266 Deauther Modules > D1 Mini (or LOLIN(WEMOS) D1 R2 & mini)
Flash Size / Partition4M (2M LittleFS) / 4M2M (Critical!)
CPU Frequency80 MHz (or 160 MHz for maximum responsiveness)
Upload Speed921600 (or 115200 if upload is unstable)
PortSelect your RF Hunter COM port
Critical Partition Scheme Setting

Selecting any partition scheme other than 4M2M (2M LittleFS) will cause flash allocation overlap errors, corrupting LittleFS and preventing the firmware from booting properly.

5. Enabling or Disabling Storage Function​

In Storage.h:

// Comment this out to disable the Storage web portal and save flash space
#define USE_STORAGE_FUNCTION

6. Compile & Upload​

Click the Upload button (or press Ctrl + U).

Method 3: Command Line (Arduino CLI)​

For automated pipelines or headless flashing, use arduino-cli:

Compile:​

arduino-cli compile --fqbn deauther:esp8266:d1_mini:eesz=4M2M .

Upload:​

arduino-cli upload -p COM3 --fqbn deauther:esp8266:d1_mini:eesz=4M2M .

Troubleshooting & FAQ​

1. "COM Port Not Detected"​

  • Verify that your USB cable supports data transmission and is not a power-only charging cable.
  • Check Windows Device Manager to ensure the CH340 or CP2102 serial driver is installed without yellow exclamation marks.

2. "Section .irom0.text' will not fit in region irom0_0_seg'"​

  • This error occurs when the compiled sketch exceeds the 1 MB IROM limit.
  • Ensure that ENABLE_MAC_LIST in oui.h is commented out: 
    // #define ENABLE_MAC_LIST
    (This frees ~244 KB of static flash memory while retaining full deauth capabilities).

3. Display Remains Blank on Boot​

  • Verify the I2C address is configured to 0x3C in A_config.h.
  • Confirm that the display driver selected is Adafruit_SH1106G / SH1106_I2C.

4. Serial Monitor Output​

  • Open the Serial Monitor at 115200 baud to view real-time debug logs during boot, attack execution, and IR learning.
