RF Hunter User Guide & Navigation

RF Hunter is controlled entirely using a 6-button directional keypad and an onboard 128x64 SH1106 OLED display. No host computer or companion smartphone app is required for everyday operation.

1. Physical Keypad Layout & Calibration​

All 6 tactile buttons are wired through a precision resistor ladder connected to the A0 (ADC0) analog pin of the ESP8266:

ButtonPrimary ActionMenu ActionCalibrated ADC Value
UPNavigate Up / Increase ValueScroll up through menu list~188
DOWNNavigate Down / Decrease ValueScroll down through menu list~240
LEFTPrevious Tab / Decrease StepJump page up / Left parameter~96
RIGHTNext Tab / Increase StepJump page down / Right parameter~331
ENTERSelect / Execute / TransmitConfirm selection, fire IR / Jammer~375
BACKCancel / Stop / ExitStop active attack, return to Main Menu~426
Analog Calibration & Debounce

The firmware applies a BTN_TOLERANCE window (±15 ADC units) and an analog debounce threshold (180 ms) to eliminate ghost triggers or erratic button bounce under varying battery voltages.

2. Display User Interface Standards​

RF Hunter features a high-contrast user interface rendered on the 1.3" monochrome OLED:

  • Inverted Selection Bar: Active selections are highlighted with a solid white rectangle and inverted black text.
  • Vertical Scrollbar: Lists longer than 4 visible rows display an accurate proportional vertical scrollbar on the right border (x=124 to 127).
  • Persistent Text Sizing: All main menu screens utilize crisp DejaVu_Sans_Mono_12 typography. Returning from sub-applications (Infrared, Storage, Deauther) restores typography and layout automatically.

3. Step-by-Step Module Walkthroughs​

Main Menu Overview​

When RF Hunter boots, the Main Menu is displayed:

Main Menu
> RF-Hunter
  Deauther-Suite
  WiPhi
  Infrared
  Storage

Use UP / DOWN to scroll, and ENTER to select a module.

Module 1: 2.4 GHz RF Jammer​

  1. From the Main Menu, highlight RF-Hunter and press ENTER.
  2. RF Hunter initializes the nRF24L01+ radio (displaying NRF-Functions Initializing... OK).
  3. Select the desired jamming mode:
    • BLE & All 2.4GHz: Sweeps across all 125 channels (2.400–2.525 GHz) continuously.
    • Just Wi-Fi: Targets standard Wi-Fi channels 1 through 11 (2.412–2.462 GHz).
  4. Press ENTER to initiate jamming. The screen indicates Jamming active.
  5. Press BACK at any time to immediately cease transmission and power down the RF carrier.

Module 2: Wi-Fi Deauther Suite​

  1. Select Deauther-Suite from the Main Menu.
  2. Scan: Navigate to Scan > Scan APs to discover all 2.4 GHz networks in range.
  3. Select: Go to Select > Accesspoints and choose the target network.
  4. Attack: Go to Attack:
    • Deauth: Transmits deauthentication frames to disconnect all stations from the chosen AP.
    • Beacon Spam: Broadcasts cloned or randomized fake Wi-Fi networks.
    • Probe: Floods the channel with probe requests.
  5. Press BACK to stop the active attack and return to the main menu.

Module 3: WiPhi (Captive Portal & Evil Twin)​

  1. Select WiPhi from the Main Menu.
  2. In the WiPhi menu:
    • Choose Scan Networks to populate available APs.
    • Choose Select AP and pick the target network.
  3. Enter Attack and select:
    • Deauth + EvilTwin: Starts the rogue open AP cloning the target SSID while deauthenticating legitimate clients from the authentic router.
  4. The live screen displays:
    • Pkts: Count of transmitted deauthentication frames.
    • Clients: Number of devices connected to the rogue portal.
    • Status: Updates to !! PW CAPTURED !! once the user submits credentials.
  5. Access Captured PW or Saved Passwords to view verified credentials stored in EEPROM.
  6. Press BACK to shut down the rogue AP and return to the Main Menu.

Module 4: Universal Infrared (IR) Remote & Learner​

Select Infrared from the Main Menu to enter the Flipper-style IR Hub:

+---------------------------+
| [IR Menu]                 |
| > Universal Remotes       |
|   Learn IR Signal         |
|   Saved Remotes           |
|   Send Signal             |
+---------------------------+

A. Using Universal Remotes (Embedded Flash Database)​

  1. Select Universal Remotes.
  2. Select an appliance category: AC (Air Conditioners), TV (Televisions), Audio (Amplifiers / Soundbars), Projector, or Fan.
  3. Select the appliance manufacturer (e.g., Samsung, LG, Sony, Mi, Daikin).
  4. Select the function button (e.g., POWER, VOL+, VOL-, MUTE, TEMP+, TEMP-).
  5. Press ENTER: The 940 nm IR transmitter fires the calibrated modulated signal. The protocol name and pulse count are rendered on screen.

B. Learning New IR Signals (IR Receiver)​

  1. Select Learn IR Signal.
  2. Point the target physical remote directly at the IR receiver (GPIO 0) at a distance of 2 to 5 cm.
  3. Press the button on the physical remote.
  4. RF Hunter decodes the raw microsecond timings, displays protocol details (e.g., NEC: 0x20DF10EF), and prompts you to:
    • Test: Retransmit immediately.
    • Save: Save to LittleFS as a .ir file under /infrared/.

C. Saved Remotes​

  1. Select Saved Remotes to browse custom remotes saved in LittleFS.
  2. Press BACK from any IR screen to return to the RF Hunter Main Menu.

Module 5: Storage Web Portal (StorageRF)​

  1. Select Storage from the Main Menu.
  2. RF Hunter launches a standalone Wi-Fi Access Point:
    • SSID: StorageRF
    • Password: StorageRF
    • IP Address: 192.168.4.1
  3. On your smartphone, tablet, or laptop:
    • Connect to the StorageRF Wi-Fi network.
    • Open any browser and navigate to http://192.168.4.1.
  4. In the web portal:
    • View /infrared/ and /WifiPhish/ directories.
    • Download saved .ir remotes and captured credential text files.
    • Upload new .ir files directly to the device flash.
  5. Press BACK on RF Hunter to safely stop the web server, shut down the AP, and return to the Main Menu.
